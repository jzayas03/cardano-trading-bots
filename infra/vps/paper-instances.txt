# Paper-run instances, one per line, as `<strategy>_<TICKER>`.
#
# THE single source of truth for which units deploy.sh enables. It used to be a hardcoded array in
# deploy.sh that listed three instances while the box ran four -- scheduled-accumulation was live but
# was never enabled for boot, so a reboot would have silently dropped a BASELINE and left the other
# runs with nothing to be compared against.
#
# Blank lines and `#` comments are ignored. Adding an instrument is a line here plus a cutover.
#
# Instrument choice is measured, not habitual: docs/ops/2026-09-16-parallel-instruments.md ranks
# eighteen tokens by round-trip cost at 500 ADA. SNEK is TWELFTH at 293.3 bps; NIGHT is second at
# 152.3 on a 4.7M ADA pool. Every strategy needs BOTH baselines on its OWN token, because the
# promotion gate compares within a token.
#
# MEMORY: ~67 MB of Private_Dirty per paper run -- what one MORE instance costs -- after #170 and
# #171 removed the npm and tsx wrappers. Eight fits the 2 GB box with ~600-700 MB spare. Sixteen does
# not, and the 4 GB box that would have fitted them was declined on 2026-09-17, so EIGHT IS THE
# CEILING here: a third and fourth instrument need one process to run several tokens, not more rows
# in this file. Check `free -m` between starts anyway.
# (The earlier figure was ~118 MB "resident" per process. That was RSS, which counts the shared node
# binary once per process; summing it across ten node processes is what made the box look full.)
